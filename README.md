# SEG

![SEG LOGO]()

## О проекте

**SEG** — это обучающая платформа для изучения основ программной инженерии, требований, управления проектами, методологий разработки и обеспечения качества. Проект реализован на Laravel и содержит:

- Статьи с теорией по ключевым темам
- Тесты с вариантами ответов и объяснениями ошибок
- Удобную структуру разделов и статей

---

## Основные разделы

- 📚 Основные понятия программной инженерии
- 📝 Всё о требованиях
- 🗂️ Управление проектом
- ⚙️ Методологии разработки ПО
- ✅ Обеспечение качества
